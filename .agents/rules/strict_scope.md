# Regra Principal Absoluta

1. **Sem Rolagem de Tela (Zero Scrollbar)**: Nenhuma tela ou modal de Ordem de Serviço deve ter barra de rolagem vertical para ver os campos. Todos os campos, opções e botões DEVEM caber 100% visíveis na tela de forma enquadrada.
2. **Foco Estrito na Solicitação**: Faça APENAS e EXATAMENTE o que for solicitado pelo usuário.
3. **Proibido Alterações Colaterais**: NUNCA modifique outros elementos que não foram indicados no pedido.
