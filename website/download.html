Como Instalar e Ativar

Passos simples para rodar no seu computador e smartphone.

1

Baixe o Arquivo

Clique no botão correspondente ao seu sistema (instalador .exe para Windows ou arquivo .apk para Android).

2

Execute a Instalação

No Windows, execute o instalador. No celular, toque no APK baixado e confirme a permissão para instalar.

3

Inicie o Uso

Abra o aplicativo, utilize a demonstração gratuita de 10 dias ou insira sua chave de licença anual para ativar.
